# ADR-024: Frontend libraries: Tailwind 4, TanStack Query 5, Motion, Stripe Payment Element

- **Status:** Accepted
- **Date:** 2026-11-11
- **Decision register:** —
- **Blueprint:** v1.1.1 §8.2

## Context

The brief names Tailwind CSS, React Query, Framer Motion and Stripe.js.

## Decision

Use their current versions: Tailwind CSS 4, TanStack Query 5, Motion (Framer Motion renamed, `motion/react`) and the Stripe Payment Element.

## Alternatives considered

- **Older major versions of the same libraries:** superseded upstream.

## Consequences

CSS-first theming with `@theme`; no `tailwind.config.ts`.
